## 📖 About This Project

The goal of this challenge is to move from basic programmatic syntax to highly optimized algorithmic thinking. Each solution in this repository is written with a focus on:
*   **Optimal Time & Space Complexity:** Moving from brute-force loops to mathematical and bitwise shortcuts ($O(1)$ solutions where possible).
*   **Clean & Readable Code:** Following standard Java naming conventions, proper comments, and structural integrity.
*   **Edge Case Handling:** Ensuring the code gracefully handles negative inputs, zeroes, and overflow scenarios.
